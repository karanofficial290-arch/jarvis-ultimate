      Saved memory

      Saved memory persists across conversations and devices. Temporary context (the current chat) is not saved here. Passwords, codes, card and ID numbers are refused automatically.

      AI provider

      Provider, model and API keys are configured on the server only (environment variables), so keys never reach phones, browsers or this page. To switch providers, change JARVIS_LLM_PROVIDER, JARVIS_LLM_MODEL and the related variables in the backend .env and restart. Supported: anthropic, openai-compatible (OpenAI, Groq, OpenRouter, a local Ollama…), and local-rules (no AI, simple commands only).

      Permissions

      Jarvis can only use tools you allow here. The AI cannot change these switches.
